# App

Expo. Dos pantallas: la sala y el detalle de una película.

```
npm install
npx expo start --web
```

La app pide los datos a `http://localhost:3000`. En el emulador de Android usa `http://10.0.2.2:3000`. Si la pruebas en un celular, cambia `API_URL` en `src/services/api.ts` por la IP de tu computadora.
